# 守望先锋共用灵敏度测试工具

一个可离线使用的单文件网页工具，用于比较几档鼠标灵敏度，并结合多日测试与游戏内检查给出建议。

## 使用

下载本仓库文件，使用 Chrome 或 Edge 打开 `overwatch-sensitivity.html`。无需安装开发环境或启动服务器。

- [使用说明](使用说明.md)
- [专业词语的简单解释](术语说明.md)
- [测试报告](测试报告.md)
- [原始开发规格](overwatch_shared_sensitivity_codex_prompt.md)

浏览器仅能读取部分屏幕和浏览器信息，不能直接获取鼠标 DPI 或游戏设置。测试数据保存在本地浏览器中，可在页面中导出备份。

## 测试

`tests/` 包含自动测试脚本、结果和截图。自动测试与真实鼠标、游戏内验证的范围见测试报告；自动测试不能替代真实设备与游戏体验验证。

测试脚本使用 Node.js 和 Playwright，其中现有运行路径对应开发时的环境，其他电脑运行测试需要调整路径。这些依赖仅用于开发测试，使用网页不需要安装。
